# Everly · 特殊人群食品评分卡片

同一种食物，对不同的人，加减分必须不一样。

六类经典人群各有一套评分系统，基于「今天吃了什么」的假设，
按 U 型双向伤害（不足→催补 / 过量→减分）对照每个人自己的健康区间打分，
每条加减分都带公开、全球公认的科学出处。

**在线点击体验：https://shi722haha.github.io/everly-people-scores/**

- 💪 健身增肌 · 🤱 哺乳产后 · 👵 老年 65+ · 🥗 素食 · 🩺 自报控糖 · 🌿 肠胃脆弱
